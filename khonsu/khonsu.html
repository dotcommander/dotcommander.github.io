    Practical Playbook

    6 "set it once, thank yourself later" examples for messy schedules

    Create any of these in plain English with Create with Prompt… in the app or via khonsu create. Click Copy to drop one straight into Khonsu.

    1. 8:00 AM "What Actually Matters Today" Brief

    Markdown Delivery

    For when you start every morning scatterbrained: Khonsu wakes up your coding agent before coffee, scans yesterday's open notes and dirty git repos, and lands 3 concrete priorities in ~/Documents/daily-{{date}}.md. 

    khonsu create "weekdays at 8am list my 3 highest-leverage tasks from ~/Notes and dirty git branches" \
  --workdir ~/Notes --agent claude
    Policy: Markdown file • Memory context ON

    2. Sunday Downloads & Desktop Cleanup Plan

    Approval Gate

    For 400 screenshots named Screenshot 2026-*: An AI task classifies stale files and writes a proposed cleanup plan — a Pipeline Approval Gate pauses before the apply stage until you click Approve & Continue Pipeline in Pending Review. 

    # Stage 1: Scan ~/Downloads -> Approval Gate -> Stage 2: Apply
"Group files older than 30 days into Archive/Installers/Receipts and print a dry-run move script without deleting anything."
    Policy: Pipeline Approval Gate • Never deletes silently

    3. Zero-Overlap Tool & CLI Updates

    Shared Lock

    For updaters you always put off running: Keep every updater task clean like jcode update, attach Shared Lock: global-updates (Skip if busy), and let Khonsu + launchd serialize them automatically. 

    Command:      jcode update
Schedule:     Daily at 09:00
Shared Lock:  global-updates  (Skip if busy)
    Resolves ~/.local/bin/jcode automatically

    4. Overnight Missing-Tests & Lint Sweep

    Git Worktree

    For side projects you mean to clean up someday: Khonsu checks out an isolated branch in ~/.khonsu/worktrees/, caps spend at $0.50/day, restricts edits to Tests/**, and shows a diff to Apply or Discard next morning. 

    # Worktree: ON · Allowed Globs: Tests/** · Daily Cap: $0.50
khonsu review nightly-test-sweep --apply
    Policy: Worktree + allowedWriteGlobs + Pending Review

    5. Friday 4:30 PM "What Did I Actually Ship?" Recap

    Cross-Run Memory

    For forgetting your own wins by Monday: Enables KHONSU_MEMORY_FILE + KHONSU_PREV_OUTPUT so your agent summarizes commits and finished tasks into one running weekly brag doc without repeating itself. 

    # Inject memory context: ON
# Delivery: Append ~/Documents/weekly-wins-{{date}}.md
"Summarize this week's commits compared against $KHONSU_PREV_OUTPUT into 5 crisp bullet points."
    Policy: Memory continuity + Markdown append

    6. Quiet-Until-Changed Watchdog

    On Output Change

    For notification fatigue: Use Khonsu's output-change notification mode and auto-stop rules (stop on output change or after 5 runs) so background checks only tap your shoulder when something actually changes. 

    # Notifications: On output change
# Auto-Stop: Pause after 3 failures or when output changes
"Check dependencies for security advisories and stay silent unless the vulnerability list changed."
    Zero noise • Auto-pauses when done
    Built to Stay Low-Friction

    Commands you can actually read six months from now

    Most schedulers force you to wrap commands in absolute paths, /usr/bin/lockf flags, and XML plists. Khonsu lets you write human commands — or simplifies legacy commands in one click.

    Before — Raw lockf & hardcoded paths
    /usr/bin/lockf -k -t0 /Users/alex/.khonsu/state/global-updates.lock /Users/alex/.local/bin/jcode update
    • Easy to mistype -t0 vs blocking forever
    • Home username hardcoded inside every single job
    • Have to copy-paste lock paths between sibling tasks
    After — Khonsu Command Simplifier
    jcode update
    Resolves to ~/.local/bin/jcode Shared Lock: global-updates Skip if busy

    Paste a legacy command and Khonsu offers 1-click Simplify: unwraps trivial sh -c wrappers, lifts lockf into policy, supports bare names & ~/ paths safely, offers Extract to Script… for inline shell snippets into ~/.khonsu/scripts/, and renders the exact lockf wrapper if you hand the job to launchd.

    Guardrails for Distracted Humans

    Automation you can trust even when you aren't watching

    Forgotten cron jobs get scary when an LLM has write access or an uncapped credit card. Khonsu puts hard local brakes in front of every scheduled run.

    Daily USD Budgets

    Per-task spend caps & 7-day ledger

    Set e.g. $0.50/day on any scheduled prompt and track fleet tokens & dollars in Usage & Spend… (⇧⌘U).

    Git Worktree Isolation

    Diff inbox instead of YOLO edits

    Coding runs happen in ~/.khonsu/worktrees/ with optional allowedWriteGlobs. Review the patch and click Apply or Discard.

    Two-Phase Approval

    SHA-256 execution digest gate

    Pin a command, args, workspace, env, and shared lock digest with Test Run & Seal; edits automatically pause unapproved runs.

    Emergency Brake

    One shortcut pauses everything

    Press ⇧⌘P or run khonsu pause-all to snapshot and freeze all schedules immediately — restore later in one click.

    Menu Bar + launchd

    Closes without stopping the clock

    Closing the window keeps Khonsu resident in your menu bar; hand eligible tasks directly to macOS launchd to survive reboots.

    Auto-Stop & Pipelines

    Bounded runs & visual DAGs

    Stop automatically after N runs, failures, or unchanged output — or chain Fetch → Summarize → Deliver on the Pipeline Board.

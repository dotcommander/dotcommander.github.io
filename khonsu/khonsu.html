From the first run to a daily schedule

Start with Run an Example to see a local task produce a short text report. Then try a task of your own.

  1. Create a task

    Click New Task and choose Command, Script, or AI Prompt. Save it as On demand to try it manually.

  2. Check what happened

    Click Run. Open Overview for the outcome, Logs for output and errors, and History for previous runs.

  3. Set a schedule

    Edit the task, choose Daily or another schedule, and check the next run and timezone. Khonsu can keep running in the menu bar when its window closes.

Save an agent prompt and use it again

In Settings → Agents, create your own agent or duplicate a starter such as Code Reviewer. Give it a name, description, and instructions.

In an AI Prompt task, Use Agent Prompt copies those instructions into the task for editing. Run with selects the available runner that executes the prompt.

Options for bigger workflows

  • Use More → Import Tasks to bring in tasks from launchd, a Taskfile, or a Justfile.
  • Open More → Pipelines to connect tasks into stages, including approval gates.
  • Configure timeouts, shared locks, or isolated Git worktrees in the task editor as needed.

Use the companion CLI

With Khonsu running and its CLI installed, try these commands after creating the hello-khonsu task.

khonsu list
khonsu run --wait hello-khonsu
khonsu status hello-khonsu
khonsu logs hello-khonsu --tail 20
